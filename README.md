# 🌱 EcoPark

Projeto semestral desenvolvido para a disciplina de **Computação Gráfica**, com foco em **educação ambiental**, **sustentabilidade** e **interatividade em ambiente 3D**, utilizando a engine **Unity**.

---

## 🎮 Sobre o Projeto

**EcoPark** é um jogo educativo em primeira pessoa onde o personagem principal precisa **revitalizar uma praça pública**, realizando diversas tarefas que abordam temas alinhados aos **Objetivos de Desenvolvimento Sustentável (ODS) da ONU**.

Cada área da praça apresenta um mini game com mecânicas próprias, ensinando de forma lúdica conceitos como:
- Conservação ambiental  
- Acessibilidade  
- Energia renovável  
- Sustentabilidade urbana  
- Cuidado com bens públicos  

---

## 🎯 Objetivos do Jogo

- Restaurar completamente a praça  
- Aprender conceitos ambientais de forma interativa  
- Completar os mini games no menor tempo possível  

---

## 🕹️ Sistema de Pontuação

- ⏱️ Pontuação baseada em **tempo**
- 🏁 Pontuação final exibida ao término do jogo
